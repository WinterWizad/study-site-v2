## Flashcards

`flashcards.md` per subject — this format, so it imports straight into Anki (or any CSV/spaced-repetition tool):

```
Question | Answer
```

One card per definition, one per trap, one per "name the stages of…". Generated from the `Self-test` and `Traps` sections of each unit file, so nothing in a flashcard is a surprise at exam time.
